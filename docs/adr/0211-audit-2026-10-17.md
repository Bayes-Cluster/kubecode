## Compatibility audit checklist

Run this whenever the upstream package changes. For each item, compare the
upstream source with the Kubecode module, update the fixture or test that pins
the behavior, and record a new dated addendum.

1. **Endpoints and headers** — endpoint paths, `bot_type`, `AuthorizationType`,
   `X-WECHAT-UIN`, `iLink-App-Id`, `iLink-App-ClientVersion`, and
   `base_info` (`server/src/ilink/client.rs`; `server/tests/ilink.rs`).
2. **Login states** — every `get_qrcode_status` value, verification-code and
   redirect handling, QR refresh (`server/src/ilink/types.rs`,
   `server/src/ilink/service.rs`; `server/tests/ilink_service.rs`).
3. **Sync** — `get_updates_buf` semantics, `longpolling_timeout_ms`, and
   `errcode -14` (`server/tests/ilink.rs`, `server/tests/ilink_e2e.rs`).
4. **Message shapes** — item types, `message_type` / `message_state`,
   `context_token`, quoted messages, voice transcription
   (`server/src/ilink/domain.rs`; `server/tests/ilink_inbound.rs`).
5. **Typing** — `getconfig` ticket and `sendtyping` statuses
   (`server/tests/ilink_outbound.rs`).
6. **CDN** — AES-128-ECB with PKCS#7, `getuploadurl` fields, upload/download URL
   fallbacks, `x-encrypted-param`, both inbound `aes_key` encodings, outbound
   `aes_key` encoding, `encrypt_type`, `mid_size`, `file_name`, `len`
   (`server/src/ilink/cdn.rs`; `server/tests/ilink_outbound.rs`).
7. **Business codes and redaction** — `ret` / `errcode` handling and the
   sensitive-field list (`server/src/ilink/error.rs`).
8. **Media routing** — upstream's MIME routing versus Kubecode's stricter
   allowlist (`server/src/shared_media.rs`).

## Decisions recorded at release

- **Unauthorized senders get one reply.** A peer's context token is stored only
  after authorization. To deliver the rejection that §7 promises, an
  unauthorized sender's context is held in memory for one reply (bounded,
  120-second lifetime) and is never persisted.
- **Images are idle-only.** Inbound images are sent to the Agent as ACP image
  blocks only when the Agent advertises `promptCapabilities.image` and the
  Session is idle. The durable prompt queue stores text, so a busy Session or a
  text-only Agent produces a localized notice instead of a silent drop. This
  replaces §10's temporary-file sketch: no inbound media touches disk.
- **Archiving clears the binding.** Besides deletion, archiving the bound
  Session clears the binding and publishes `ilink_status_changed` with a
  `binding_reason`, so every browser can explain the cleared binding.
