# Kubecode brand assets

The canonical identity is **Workspace Loop / Modular Flow**. The outer blue
paths represent the Project and reconnectable Session, while the mint node
represents the active Agent or task.

## Palette

| Role | Value |
| --- | --- |
| Kube Ink | `#11131A` |
| Workspace Blue | `#4F63F5` |
| Blue Light | `#91A0FF` |
| Agent Mint | `#2BD9A8` |
| Warm Surface | `#ECE9E2` |

## Files

- `public/logo.svg` is the canonical square App Icon.
- `public/favicon.svg` is the browser favicon.
- `kubecode-mark-light.svg` is the monochrome mark for light backgrounds.
- `kubecode-mark-dark.svg` is the monochrome mark for dark backgrounds.
- `kubecode-mark-color.svg` is the transparent color mark.
- `kubecode-horizontal-light.svg` and `kubecode-horizontal-dark.svg` are the
  canonical wordmarks.
- `kubecode-mark-512.png` is the square raster export.
- `kubecode-social-preview.svg` is the editable social-card source.
- `kubecode-social-preview.png` is the GitHub social-preview export.

## Usage

- Preserve the mark's aspect ratio and transparent padding.
- Use the color mark or a monochrome variant without recoloring individual
  segments.
- Do not place Agent logos inside the Kubecode mark.
- Do not add shadows, outlines, rotation, or text inside the mark.
- Use the written name **Kubecode** next to the mark when context is ambiguous.

See `BRAND_GUIDE.md` for clear space, minimum sizes, color semantics, and
prohibited treatments. The SVG sources are deterministic repository assets;
regenerate PNG exports from their SVG source rather than editing rasters.
