# 微信

[文档](../README.md) · [English](../../guides/wechat.md)

Kubecode 可以绑定一个微信账号，让你在手机上使用 Session：发送提示词、查看
Agent 的回复、回答授权问题、停止或调整正在进行的工作。Kubecode 服务器直接与
腾讯 iLink bot 服务通信；浏览器从不访问腾讯，也不需要安装 Node.js 或 OpenClaw。

## 开始之前

- Kubecode 服务器需要能以 HTTPS 访问腾讯 iLink 主机（`*.qq.com` 与
  `*.wechat.com`，仅 HTTPS）。其他任何目标都会被拒绝，包括腾讯响应中指向的主机。
- 需要一个可以扫描 bot 登录二维码的微信账号。每个 Kubecode Runtime 只能绑定一个
  微信账号。
- 通道消息使用服务器的语言设置：设置 `KUBECODE_ILINK_LANGUAGE=zh-CN` 使用简体
  中文（默认为英文）。

## 连接

1. 打开 **设置 → 微信**，选择 **连接微信**。
2. 在微信中点击 **+**，选择 **扫一扫**，扫描二维码。二维码过期前会自动刷新几次。
3. 如果微信显示一个数字，在 **验证码** 中输入并提交。针对旧二维码输入的数字会被
   拒绝，请使用当前二维码对应的数字。
4. 状态变为 **已连接**。扫码的微信用户即为已授权联系人。

服务器重启后绑定依然有效。如果之后微信拒绝已保存的登录，状态会显示
**登录已过期**，请选择 **获取新二维码** 重新扫描。

## 选择当前 Session

来自微信的消息只会发送到一个 **当前会话**。可在 **设置 → 微信 → 当前会话** 中选择，或在侧边栏 Session 菜单中使用 **用于微信**。当前 Session 在侧边栏
中会显示微信标记。

已归档、只读、Team 与子 Agent Session 不能作为当前 Session。如果当前 Session
被归档或移除，绑定会被清除——Kubecode 不会自动选择替代 Session——设置页会说明
原因。

## 在微信中使用

- **提示词：** 可发送文字、带有微信转写文本的语音或图片。Session 忙碌时文字提示词
  会进入队列。只有在 Session 空闲且其 Agent 支持图片时才会发送图片，否则会收到
  简短说明。
- **回复：** Agent 的文字会以不超过 2,000 字符的段落发送，在调用工具前和本轮结束时
  推送，Agent 工作期间显示“正在输入”。过长的回复会被截断并附说明，完整内容始终可在
  Kubecode 中查看。
- **文件：** 当 Agent 明确分享 Session 所在 Project 中的文件（10 MiB 以内的图片、
  PDF、文本、Markdown、CSV、JSON、ZIP 与 Office 文档）时，会以图片或附件形式送达。
  模型输出的文字永远不会被当作文件路径。
- **授权：** 授权问题会以编号列表发送，回复编号即可选择。只接受 Agent 提供的选项，
  微信永远不会放宽 Session 的权限配置。

### 命令

命令必须以 `!` 或 `！` 开头。每个命令都会先停止当前 Session 正在进行的运行。

| 命令 | 作用 |
| --- | --- |
| `!` | 显示状态：Session、Project、Agent、模式/模型、运行与队列状态 |
| `!s` | 切换当前 Session（`!s 2` 查看下一页） |
| `!n` | 新建 Session：先选择 Project，再选择 Agent |
| `!m` | 在 Session 空闲时切换模型或模式 |
| `!q` | 发送快捷提示词 |

回复菜单中显示的编号即可。菜单两分钟后失效，且只属于打开它的联系人。快捷提示词可在
**设置 → 微信 → 快捷提示词** 中配置。

## 断开连接

**设置 → 微信 → 断开连接** 会先要求确认，然后从此 Runtime 中移除已保存的微信凭据、
联系人、同步位置、快捷提示词与当前会话选择。Session、provider 历史与 Project
文件永远不会被改动。停止服务器会保留绑定，供下次启动使用。

## 隐私与安全

- 凭据与微信回复上下文使用状态目录中的本机密钥（`ilink/secret.key`，仅服务器用户
  可读）加密保存，断开连接时删除。
- 浏览器只会收到连接状态与渲染后的二维码图片——永远不会收到 token、二维码标识、
  联系人 ID 或腾讯响应。
- 日志、分析与工作区事件中永远不包含 token、提示词、文件名、文件内容或路径。分析
  只记录操作与分类结果。
- 只有已授权联系人可以驱动 Session。其他人发送的消息每十分钟最多收到一次“不可用”回复，
  不会产生其他效果；服务器重启后也不会重放或再次回复这些消息。

## 故障排查

| 现象 | 处理方法 |
| --- | --- |
| 连接后立即显示 **连接错误** | 检查服务器到 `*.weixin.qq.com` 的 HTTPS 出站访问后重试。 |
| **验证已锁定** | 输入错误次数过多。选择 **获取新二维码**。 |
| 一直显示 **正在重新连接** | 服务器会以退避方式持续重试，请检查其网络。**重新连接** 会在短暂冷却后立即重试。 |
| **登录已过期** | 微信拒绝了已保存的登录。选择 **获取新二维码** 并重新扫描。 |
| 账号仍已绑定但显示 **未连接** | 选择 **重新连接** 恢复已保存的登录，或选择 **获取新二维码** 重新扫描。 |
| 微信提示未绑定 Session | 在设置中或通过 `!s` 选择当前 Session。 |
| 分享的文件没有送达 | 只有位于 Session 所在 Project 中、属于允许类型且小于 10 MiB 的文件才会发送。请在 Kubecode 中打开 Session 获取。 |
| 完全没有回复 | 微信只允许回复最近给 bot 发过消息的联系人；发送任意消息刷新会话即可。 |
